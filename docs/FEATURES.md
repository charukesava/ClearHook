# ClearHook - Features & Capabilities

## Core Features

### 1. Real-time Phishing Analysis ✅
- Analyzes SMS, emails, and messages instantly
- Risk scoring from 0-100%
- Color-coded severity (red/orange/yellow/green)
- Response time: 3-5 seconds

### 2. Red Flag Detection 🚩
Detects:
- Urgency language ("Click now", "Verify immediately")
- Shortened/suspicious URLs (bit.ly for banking)
- Spoofed domains (amaz0n instead of amazon)
- Requests for sensitive info (passwords, OTP)
- Grammar/spelling errors (classic scam marker)
- Unusual offers or threats
- Emotional manipulation tactics

### 3. Explainable Results 💡
For each analysis:
- **Why it's suspicious**: Plain English explanation
- **Specific red flags**: List of detected issues
- **What to do**: Clear action recommendations
- **Context**: Cultural awareness for Indian scams

### 4. Session History 📋
- Track last 10 analyses
- Quick re-analysis of similar messages
- Timestamp tracking
- Risk score at a glance

### 5. Production-Ready Security 🔐
- Rate limiting (10 requests/min)
- Input validation (5-5000 chars)
- CORS protection
- Environment-based configuration
- No API key exposure
